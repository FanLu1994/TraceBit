Windows에서 로컬 우선으로 동작하는 독립적인 행동 기록 및 AI 도구 개선 제안 앱입니다.

> Alma Recorder에서 영감을 받았습니다.

TraceBit은 활동 구간 단위로 포그라운드 앱, 창 제목, 유휴/잠금 상태, 중복이 제거된 화면 스냅샷을 기록하고, 매일의 기록을 로컬에서 번호가 붙은 근거로 계산하며, 사용자의 작업 방식을 계속 학습합니다: 주로 쓰는 도구, 늘 반복되는 오가기, 결과물을 내는 리듬, 되풀이해서 다루는 프로젝트와 사이트. AI의 역할은 습관을 바로잡는 것이 아니라, 이미 하고 있는 일을 바탕으로 단계를 줄여 주는 도구, 플러그인, 설정, 오픈소스 대체를 제안하는 것입니다.

현재 버전은 완전한 **Rust + GPUI** 네이티브 앱입니다. UI, 수집, 저장, AI 요청, 시스템 통합이 모두 Rust로 구현되어 있으며 Node.js, Electron, WebView, HTML/CSS, PowerShell이 필요하지 않습니다.

## 설치

Windows 10/11이 필요하며 Rust나 다른 런타임은 필요하지 않습니다.

최신 설치 패키지 **[TraceBit Setup(Releases)](https://github.com/FanLu1994/TraceBit/releases/latest)** 를 내려받아 실행합니다:

- `%LOCALAPPDATA%\Programs\TraceBit`에 설치하고 시작 메뉴와 바탕 화면 바로 가기를 만듭니다
- 덮어쓰기 설치를 해도 `%APPDATA%\TraceBit`의 기록은 유지됩니다
- 제거해도 개인 기록은 자동으로 삭제되지 않으므로 필요하면 `%APPDATA%\TraceBit`를 직접 정리하십시오

## 사용

왼쪽 내비게이션은 4개 페이지로 구성되어 있으며, 페이지는 단축키로 전환합니다:

| 단축키 | 페이지 | 내용 |
| --- | --- | --- |
| `Ctrl+1` | 오늘 활동 | 당일 타임라인, 앱 순위, 분류 비중, 스냅샷 다시 보기 |
| `Ctrl+4` | 최근 통계 | 7 / 14 / 30일 요약, 일별 곡선, 활동 시간대, 일별 상세 |
| `Ctrl+2` | AI 제안 | 당일 결론, 도구 개선 후보, 전체 HTML 보고서 열기 |
| `Ctrl+3` | 설정 | 기록, 스크린샷, 사이트, AI, 알림과 시스템 통합 |

기타 단축키: `Ctrl+Shift+R` 기록 시작/일시정지, `Ctrl+W` 창 닫기, `Esc` 오버레이 닫기, `Tab` / `Shift+Tab` 포커스 전환.

### AI 설정

「설정 → AI 분석」을 열고 다음을 입력합니다:

- **인터페이스 주소**: 예: `https://api.deepseek.com/v1`, 로컬 Ollama는 `http://localhost:11434/v1`
- **API Key**: 로컬 Ollama는 비워 둘 수 있으며 Windows DPAPI로 암호화해 저장합니다
- **모델 이름**: 이미지 입력을 지원하는 멀티모달 모델을 권장합니다. 예: `qwen2.5vl`(로컬 Ollama), `gpt-4o-mini`. 텍스트 제안만 쓸 때는 `deepseek-chat`, `qwen-plus` 같은 텍스트 전용 모델도 됩니다

인터페이스 주소는 입력한 내용 그대로 사용하며, 순수 도메인(예: `http://localhost:11434`)만 `/v1`이 자동으로 붙습니다. 따라서 `/v1beta/openai`, `/api/paas/v4` 같은 경로도 그대로 입력할 수 있습니다. 요청은 JSON 출력 모드를 사용하고(서비스가 지원하지 않으면 자동으로 대체), 429/5xx가 나면 재시도하며, 출력이 잘리면 오류를 명확히 보고합니다.

저장한 뒤 「연결 테스트」를 실행하고, 「AI 제안」에서 날짜를 선택해 생성을 누르면 됩니다. 생성 전에 「전송 내용 보기」를 눌러 전송될 전체 텍스트를 확인할 수 있습니다. 「매일 자동 생성」을 켜면 정해진 시각에 당일 제안을 생성하고 Windows 알림을 보냅니다. 그 시각에 PC가 절전 상태이거나 프로그램이 실행 중이 아니었거나, 생성 후 활동이 많았다면 다음 날 다시 생성하며, 수동으로 생성한 제안은 덮어쓰지 않습니다.

업무 프로필은 앱이 시작될 때 최근 30일을 자동으로 채우고, 이후 10분마다 당일분을 한 번 갱신하며, AI 설정 여부와는 무관합니다. 프로필은 로컬 JSON이므로 언제든지 확인하거나 삭제할 수 있고, 삭제하면 다음 시작 시 다시 학습합니다.

## 기능

### 기록

- 포그라운드 앱과 창 제목을 기록하고 개발, 브라우저, 커뮤니케이션, 회의, 문서 등으로 자동 분류합니다
- Windows의 실제 키보드·마우스 유휴 시간을 기준으로 활동 구간을 나눕니다. 회의, 전체 화면 영상 시청, 화면 발표 중에는 더 긴 유휴 임계값을 사용하며, 잠금/절전 중에는 수집을 멈춥니다
- Alt-Tab으로 스쳐 지나간 순간적인 창은 걸러내고, 창 제목과 사이트별 체류 시간을 집계합니다. 자정을 넘긴 활동도 유실되지 않습니다
- 앱 전환 시와 정기 하트비트에 스크린샷을 찍습니다(포그라운드 창이 있는 모니터를 캡처). 썸네일 해시, 히스토그램, 픽셀 차이의 3단계 중복 제거를 적용합니다
- 웹사이트 기록은 선택 사항입니다. 직접 켜면 Windows UI Automation을 통해 현재 브라우저의 도메인만 저장하고, 브라우저 시간을 사이트별로 개발, 문서, 엔터테인먼트 등의 분류에 배분합니다
- 단일 인스턴스로 실행되며 창과 트레이 아이콘이 실행 파일에 내장되어 별도의 리소스 디렉터리가 없습니다

### UI와 통계

- GPUI 네이티브 UI: 오늘 활동, 24시간 타임라인, 분류 비중, 앱 순위, 스냅샷 다시 보기
- UI 언어: 简体中文, English, 日本語, 한국어. 기본값은 Windows 표시 언어를 따르며, 저장하면 즉시 적용됩니다
- 최근 통계: 7 / 14 / 30일 개요, 일별 활동 곡선, 활동 시간대, 자주 쓰는 앱과 분류 비중, 자주 가는 사이트, 클릭해서 열 수 있는 일별 상세
- 일별 상세에서 아무 행이나 클릭하면 그날의 오늘 활동으로 바로 이동합니다
- 시스템 트레이, 트레이로 닫기, 부팅 시 자동 시작, 용량 순환, 한 번에 비우기

### 업무 프로필과 AI 제안

- 업무 프로필: 기록한 날마다의 데이터를 하나의 장기 프로필로 병합합니다(주력 도구와 용도, 일상적인 오가기, 활동 리듬, 되풀이해서 다루는 프로젝트와 사이트). AI 제안의 장기 근거가 됩니다
- AI 도구 개선 제안: 근거와 장기 프로필은 로컬에서 계산하고, AI는 사용자의 작업 방식을 이해한 뒤 구체적인 도구, 플러그인, 단축키, 설정, 자동화로 이어지는 개선을 제시합니다. 각 항목은 반드시 근거 번호를 인용해야 하며, 검증할 수 없는 숫자는 표시됩니다
- 도구 개선만 하고 습관을 강요하지 않습니다: 줄이기, 끊기, 정해진 시간에 몰아서 처리하기, 일찍 자기 등을 요구하는 내용은 로컬 규칙으로 걸러지고, 보고서에는 지금 하는 동작을 더 수월하게 만드는 제안만 남습니다
- 오픈소스 대체: 로컬 규칙이 오래 써 온 상용 도구(API 클라이언트, 데이터베이스 클라이언트, 디자인/편집 소프트웨어, 원격 제어, 압축 도구 등)를 식별해 사용 방식이 비슷한 오픈소스 대체를 제시하며, AI는 번호로만 인용할 수 있습니다
- 채택 피드백 루프: 앱 안에서 「채택함 / 불필요」를 표시합니다. 무시한 후보는 다시 제안하지 않고, 채택한 도구는 다음 보고서에서 같은 유형의 오가기 변화를 자동으로 비교합니다
- 일일 알림: 기본적으로 10:30에 어제의 결론과 한마디 인사를 시스템 알림으로 보냅니다. 어제 기록이 없으면 알리지 않으며, 끄거나 시간을 바꿀 수 있고, 시각을 놓치면 그날 한 번 더 보냅니다
- 전체 보고서는 별도 HTML 페이지로 브라우저에서 열립니다: 업무 프로필, 당신의 작업 방식, 도구 개선 기회, 다음 자동 확인, 채택 회고, 기타 후보 도구가 담기며, 근거 번호를 클릭해 이동할 수 있고 다크 모드와 인쇄를 지원합니다
- 관찰만 하고 숙제를 내지 않습니다: 보고서는 다음에 비교해 볼 지표 몇 가지를 기록하고 자동으로 확인하며, 별도의 실험을 수행할 필요가 없습니다
- 선택적 스크린샷 구간 요약: 정시에 맞춰 나눈 구간에서 스냅샷을 골라 당시의 포그라운드 앱과 함께 위에서 설정한 멀티모달 모델이 요약하며, 요약은 제안의 근거로 사용됩니다
- 도구화할 수 있는 작업 추천: 로컬 규칙이 실제 전환과 체류 시간 근거를 바탕으로 오픈소스 프로젝트, Skill, MCP를 매칭해 후보로 AI에 넘깁니다
- 선택적 웹 리소스 검색: DuckDuckGo와 Brave Search를 지원하며, 실패하면 로컬 큐레이션 추천을 유지합니다
- OpenAI 형식 인터페이스 호환: DeepSeek, 通义, Kimi, OpenAI, 로컬 Ollama 등
- 제안 자동 생성(시각을 놓치면 다시 생성하며, 수동 생성 결과는 덮어쓰지 않음)

## 데이터와 개인정보

데이터는 기본적으로 다음 위치에 있습니다:

```text
%APPDATA%\TraceBit\
├── settings.json             # 설정, API Key는 DPAPI로 암호화
├── profile.json              # 로컬에서 학습한 업무 프로필(하루에 한 줄)과 도구 결정
├── digest.json               # 일일 알림 상태(가장 최근 알림 날짜)
├── data\
│   ├── days\YYYY-MM-DD.jsonl # 포그라운드, 유휴, 잠금, 스냅샷 인덱스 이벤트
│   └── snapshots\YYYY-MM-DD\ # JPG 스냅샷
├── reports\YYYY-MM-DD.json   # 생성된 제안(근거, 업무 프로필, 도구 결정, token 사용량 포함)
├── reports\YYYY-MM-DD.html   # 같은 제안의 브라우저용 보고서
└── intervals\
    ├── YYYY-MM-DD.jsonl      # 스크린샷 구간 요약
    ├── last_request.json     # 비전 모델에 마지막으로 보낸 텍스트와 스냅샷 목록
    └── cursor.json           # 구간 분석 진행 상태
```

Rust 버전은 이 형식을 그대로 사용하므로 이전 버전의 기록 데이터를 바로 읽을 수 있습니다. 새로 기록되는 이벤트에는 `v` 버전 번호가 붙으며, 이전 형식도 계속 읽을 수 있습니다.

- 활동 기록, 스크린샷, 요약은 이 PC에 저장되고 키보드 입력 내용은 기록하지 않습니다. 원격 AI를 사용할 때는 아래에 나열한 내용만 전송합니다.
- 웹사이트 기록은 기본적으로 꺼져 있습니다. 직접 켜면 Windows UI Automation을 통해 지원되는 브라우저의 주소 표시줄만 읽습니다. 사이트 기록은 도메인만 저장하며 경로, 쿼리 매개변수, 페이지 내용은 저장하지 않습니다. 화면 스냅샷은 별도 스위치로 제어합니다.
- 잠금 및 절전 상태에서는 포그라운드 활동을 기록하지 않고 스크린샷도 찍지 않습니다.
- 민감한 키워드(앱 이름, 제목, 사이트로 판단)에 해당하는 포그라운드 창: 제목은 디스크에 `[敏感窗口]`로 저장되고, 스크린샷을 찍지 않으며 사이트도 기록하지 않습니다. 키워드는 설정에서 직접 추가하거나 삭제할 수 있습니다.
- AI 제안은 로컬에서 계산한 비식별화 근거만 전송합니다: 체류 시간, 횟수, 분류, 앱 이름, 잘린 창 제목, 그리고 로컬에서 집계한 장기 업무 프로필(도구 이름, 오가기 앱 쌍, 리듬, 반복되는 창 제목). 채팅류 앱은 앱 이름만 보내고 대화 제목은 보내지 않습니다. **스크린샷 자체와 방문한 웹사이트 도메인은 제안 모델에 전송되지 않으며**, 사이트 목록은 로컬 보고서에만 표시됩니다. 스크린샷 구간 요약(켜 둔 경우)은 텍스트 형태로 근거에 포함됩니다.
- 스크린샷 구간 분석은 기본적으로 꺼져 있습니다. 켜면 스냅샷이 위에서 설정한 모델 인터페이스(로컬 또는 클라우드)로 전송됩니다. 화면에는 창 제목, 웹사이트 주소, 대화 내용 또는 기타 민감한 정보가 포함될 수 있으므로 프라이버시가 중요하면 로컬 멀티모달 모델을 사용하십시오.
- 웹 리소스 검색은 기본적으로 꺼져 있습니다. 켜면 검색 서비스는 내장된 추상 도구 키워드만 받고, 창 제목, 사이트 도메인, URL, 스크린샷, 사용자 행동 통계는 받지 않습니다. 출처 링크 검증은 리소스의 공개 주소에만 접속합니다.
- 텍스트는 전송 전에 이메일, 키와 토큰, 카드 번호, 신분증 번호, 휴대전화 번호, IP, 매개변수가 붙은 링크, `C:\Users\<사용자 이름>` 경로를 가립니다. 프라이버시가 중요하면 로컬 모델을 사용할 수 있습니다.
- 스냅샷은 포그라운드 창이 있는 모니터를 캡처합니다. 민감 키워드는 포그라운드 앱, 제목, 사이트로 판단하므로 배경 창 안의 민감한 내용은 식별할 수 없습니다.

## 개발

stable Rust(MSVC 툴체인)와 Visual Studio 2022 C++ 빌드 도구를 설치한 다음:

```bash
cargo run
```

`start.cmd`를 더블클릭해도 됩니다.

### 자체 테스트

```bash
cargo test                  # 설정, 저장, 통계, 비식별화, 추천, 모의 AI 전체 경로
cargo run -- --native-smoke # 실제 포그라운드 창 수집과 JPEG 스크린샷
```

`scripts\smoke.cmd`를 실행해도 됩니다. 네이티브 smoke는 임시 디렉터리를 사용하고, 종료 후 테스트 기록과 스크린샷을 삭제하므로 실제 데이터를 건드리지 않습니다.

### 패키징

[NSIS 3](https://nsis.sourceforge.io/)를 설치한 다음 실행합니다:

```bat
scripts\dist.cmd
```

스크립트는 `cargo build --release`를 실행하고 `dist\TraceBit Setup <버전>.exe`를 생성합니다. 배포 프로그램은 아이콘이 내장된 `tracebit.exe` 하나뿐이며 Electron 런타임과 PowerShell 스크립트가 없습니다.

`v*` 태그를 푸시하면 `.github/workflows/release.yml`이 자동으로 빌드해 설치 패키지를 해당 Release에 업로드합니다. 커밋과 PR은 `.github/workflows/ci.yml`이 fmt, clippy, test, release 빌드를 실행합니다.

### 디렉터리 구조

```text
src/
  main.rs            # 프로그램 진입점과 smoke 명령
  app.rs             # GPUI 창, 4개 페이지 UI, 트레이, 백그라운드 작업
  input.rs           # 네이티브 GPUI 텍스트 입력 컴포넌트
  platform.rs        # Win32, UIA, 창 아이콘, 자동 시작, 알림
  i18n.rs            # 简体中文 / English / 日本語 / 한국어 텍스트 선택과 언어 감지
  recorder.rs        # 수집 스레드, 스크린샷 중복 제거, 프라이버시 규칙
  store.rs           # JSONL 일별 저장과 타임라인/활동 구간/앱/사이트/분류 통계
  stats.rs           # 최근 기간의 주기 통계 집계
  insights.rs        # 로컬 지표와 번호가 붙은 근거(집중 작업, 방해, 파편화, 추세)
  profile.rs         # 장기 업무 프로필: 도구, 오가기, 리듬, 반복 프로젝트, 도구 결정
  analyzer.rs        # 제안 생성: 프롬프트, JSON 검증, 업무 프로필, 역량 경계 필터, Markdown 렌더링
  report_html.rs     # 제안의 독립 HTML 보고서
  llm.rs             # OpenAI 호환 호출: JSON 모드, 재시도, 잘림 감지
  redact.rs          # 전송 전 비식별화와 제목 정리
  secret.rs          # DPAPI 키 암호화
  intervals.rs       # 스크린샷 구간 분석, 멀티모달 요청, 이미지 인코딩, 요약 저장
  recommendations.rs # 로컬 작업 식별과 큐레이션 리소스(AI의 도구 후보)
  web_search.rs      # 선택적 추상 검색, 필터링, 출처 검증
  categories.rs      # 앱과 사이트 분류, 회의 인식
  settings.rs        # 이전 버전 camelCase와 호환되는 로컬 설정
assets/              # 빌드 시 내장되는 아이콘
build.rs             # Windows exe 아이콘 리소스
installer.nsi        # NSIS 설치 패키지 정의
scripts/dist.cmd     # Release와 설치 패키지 빌드
scripts/smoke.cmd    # 단위 테스트와 실제 수집 smoke
```
