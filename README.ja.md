独立した、Windows ローカルファーストの行動記録と AI ツール改善提案のアプリです。

> Alma Recorder に着想を得ています。

TraceBit は活動段ごとに、前面のアプリ、ウィンドウタイトル、アイドル／ロック状態、重複を除いたスクリーンスナップショットを記録し、毎日の記録をローカルで番号付きの根拠に変換します。さらに、よく使うツール、決まった行き来、作業のリズム、繰り返し扱うプロジェクトやサイトといったあなたの働き方を継続的に学習します。AI の役割は習慣を正すことではなく、すでに行っている作業をもとに、より少ない手数で済むツール、プラグイン、設定、オープンソースの代替を提案することです。

現在のバージョンは完全な **Rust + GPUI** ネイティブアプリです。UI、収集、保存、AI リクエスト、システム連携のすべてを Rust で実装しており、Node.js、Electron、WebView、HTML/CSS、PowerShell は必要ありません。

## インストール

Windows 10/11 が必要です。Rust やその他のランタイムは不要です。

最新のインストーラー **[TraceBit Setup（Releases）](https://github.com/FanLu1994/TraceBit/releases/latest)** をダウンロードして実行します。

- `%LOCALAPPDATA%\Programs\TraceBit` にインストールし、スタートメニューとデスクトップにショートカットを作成します
- 上書きインストールしても `%APPDATA%\TraceBit` の記録は保持されます
- アンインストールしても個人の記録は自動削除されません。必要に応じて `%APPDATA%\TraceBit` を手動で削除してください

## 使い方

左側のナビゲーションは 4 ページで、ショートカットキーで切り替えます。

| ショートカット | ページ | 内容 |
| --- | --- | --- |
| `Ctrl+1` | 今日の活動 | 当日のタイムライン、アプリ別ランキング、分類の内訳、スナップショットの振り返り |
| `Ctrl+4` | 最近の統計 | 7 / 14 / 30 日の集計、日別の推移、アクティブな時間帯、日別の内訳 |
| `Ctrl+2` | AI 提案 | 当日のまとめ、ツール改善の候補、HTML レポート全体を開く |
| `Ctrl+3` | 設定 | 記録、スクリーンショット、サイト、AI、通知とシステム連携 |

その他のショートカット：`Ctrl+Shift+R` で記録の開始／一時停止、`Ctrl+W` でウィンドウを閉じる、`Esc` でオーバーレイを閉じる、`Tab` / `Shift+Tab` でフォーカスを移動します。

### AI の設定

「設定 → AI 分析」を開き、次の項目を入力します。

- **エンドポイント URL**：たとえば `https://api.deepseek.com/v1`、ローカルの Ollama なら `http://localhost:11434/v1`
- **API Key**：ローカルの Ollama では空欄でもかまいません。Windows DPAPI で暗号化して保存します
- **モデル名**：画像入力に対応したマルチモーダルモデルを推奨します（例：`qwen2.5vl`（ローカル Ollama）、`gpt-4o-mini`）。テキストだけの提案でよければ、`deepseek-chat` や `qwen-plus` などのテキスト専用モデルも使えます

エンドポイントは入力した内容がそのまま使われ、純粋なドメインのみ（例：`http://localhost:11434`）`/v1` が自動補完されます。そのため `/v1beta/openai` や `/api/paas/v4` などのパスもそのまま指定できます。リクエストは JSON 出力モードを使用し（サービスが未対応の場合は自動的にフォールバック）、429/5xx では再試行し、出力が打ち切られた場合は明確にエラーを返します。

保存後に「接続テスト」を実行し、「AI 提案」で日付を選んで生成します。生成前に「送信内容を確認」を押すと、送信されるすべてのテキストを確認できます。「毎日の自動生成」を有効にすると、指定時刻にその日の提案を生成して Windows 通知を送ります。そのとき PC がスリープしていた場合やアプリが起動していなかった場合、または生成後に大量の活動があった場合は、翌日に追加生成されますが、手動で生成した提案は上書きされません。

ワークプロファイルはアプリ起動時に直近 30 日分が自動で補完され、その後は 10 分ごとに当日分を更新します。AI を設定しているかどうかには依存しません。プロファイルはローカルの JSON で、いつでも表示・削除できます。削除すると次回起動時に再学習します。

## 機能

### 記録

- 前面のアプリとウィンドウタイトルを記録し、開発、ブラウザ、コミュニケーション、会議、ドキュメントなどに自動分類します
- Windows の実際のキーボード・マウスのアイドル時間をもとに活動段を区切ります。会議中や全画面での動画視聴・プレゼン中はアイドルしきい値を長めにし、ロック／スリープ中は収集を停止します
- Alt+Tab で通り過ぎた一瞬のウィンドウを除外し、ウィンドウタイトルとサイト別に滞在時間を集計します。日付をまたぐ活動も失われません
- アプリ切り替え時と定期ハートビートでスクリーンショットを撮影します（前面ウィンドウのあるモニターをキャプチャ）。サムネイルのハッシュ、ヒストグラム、ピクセル差分の 3 段階で重複を排除します
- 任意のブラウジング記録：明示的に有効にすると、Windows UI Automation 経由で現在のブラウザのドメインのみを保存し、サイト別にブラウザ時間を開発、ドキュメント、エンタメなどの分類に振り分けます
- 単一インスタンスで動作し、ウィンドウとトレイのアイコンは実行ファイルに埋め込まれているため、追加のリソースディレクトリは不要です

### UI と統計

- GPUI ネイティブ UI：今日の活動、24 時間タイムライン、分類の内訳、アプリ別ランキング、スナップショットの振り返り
- 表示言語：簡体字中国語、English、日本語、한국어。既定では Windows の表示言語に従い、保存するとすぐに反映されます
- 最近の統計：7 / 14 / 30 日の概要、日別のアクティブ推移、アクティブな時間帯、よく使うアプリと分類の内訳、よく訪れるサイト、クリックで開ける日別の内訳
- 日別の内訳で任意の行をクリックすると、その日の今日の活動へ直接移動します
- システムトレイ、トレイへの格納、スタートアップ登録、容量のローテーション、ワンクリックでの消去

### ワークプロファイルと AI 提案

- ワークプロファイル：記録した各日を長期的なプロファイルに統合します（主力ツールと用途、日常的な行き来、アクティブのリズム、繰り返し扱うプロジェクトやサイト）。AI 提案の長期的な根拠になります
- AI ツール改善提案：根拠と長期プロファイルはローカルで計算し、AI はあなたの働き方を理解したうえで、具体的なツール、プラグイン、ショートカット、設定、自動化に落とし込んだ改善を提示する役割だけを担います。各項目は根拠の番号を引用する必要があり、検証できない数値には印が付きます
- ツール改善に限定し、習慣の変更は強制しません。作業を減らす、やめる、時間を決めてまとめて処理する、早く寝るといった内容はローカルルールで除外され、レポートには今の動作を楽にする提案だけが残ります
- オープンソースの代替：長期間使われている商用ツール（API クライアント、データベースクライアント、デザイン／動画編集ソフト、リモート操作、圧縮ツールなど）をローカルルールで検出し、操作感の近いオープンソースの代替を提示します。AI は番号で参照するだけです
- 採用のフィードバックループ：アプリ内で「採用済み / 不要」を付けられます。無視した候補は再び提案されず、採用したツールは次回のレポートで同種の行き来の変化が自動で比較されます
- 毎日の通知：既定では 10:30 に、昨日のまとめと一言をシステム通知で届けます。昨日の記録がない日は通知せず、オフにしたり時刻を変更したりできます。時刻を過ぎた場合はその日のうちに 1 回だけ送信します
- レポート全体は独立した HTML ページとしてブラウザで開きます：ワークプロファイル、あなたの働き方、ツール改善の機会、次回の自動照合、採用の振り返り、その他の候補ツールを収録し、根拠の番号をクリックすると該当箇所へ移動します。ダークモードと印刷に対応します
- 見守るだけで、宿題は出しません：レポートは次回比較すべき指標をいくつか記録して自動で照合します。実験を行う必要はありません
- 任意のスクリーンショット時間帯サマリー：正時で区切った時間帯からスナップショットを選び、そのときの前面アプリと合わせて、上で設定したマルチモーダルモデルが要約します。要約は提案の根拠として使われます
- ツール化できる操作の推薦：実際の切り替えと時間の根拠をもとに、ローカルルールがオープンソースプロジェクト、Skill、MCP を照合し、候補として AI に渡します
- 任意のオンライン検索：DuckDuckGo と Brave Search に対応し、失敗した場合はローカルの厳選候補を残します
- OpenAI 形式の API に対応：DeepSeek、通义、Kimi、OpenAI、ローカルの Ollama など
- 提案の自動生成（時刻を過ぎた場合は追加生成しますが、手動生成の結果は上書きしません）

## データとプライバシー

データの既定の保存先は次のとおりです。

```text
%APPDATA%\TraceBit\
├── settings.json             # 設定。API Key は DPAPI で暗号化
├── profile.json              # ローカルで学習したワークプロファイル（1 日 1 件）とツールの決定
├── digest.json               # 毎日の通知の状態（直近に通知した日付）
├── data\
│   ├── days\YYYY-MM-DD.jsonl # 前面ウィンドウ、アイドル、ロック、スナップショットの索引イベント
│   └── snapshots\YYYY-MM-DD\ # JPG スナップショット
├── reports\YYYY-MM-DD.json   # 生成済みの提案（根拠、ワークプロファイル、ツールの決定、token 使用量を含む）
├── reports\YYYY-MM-DD.html   # 同じ提案のブラウザ版レポート
└── intervals\
    ├── YYYY-MM-DD.jsonl      # スクリーンショット時間帯のサマリー
    ├── last_request.json     # 直近にビジョンモデルへ送ったテキストとスナップショットの一覧
    └── cursor.json           # 時間帯分析の進捗
```

Rust 版もこれらの形式を踏襲しており、旧版の履歴データをそのまま読み取れます。新しく書き込むイベントには `v` のバージョン番号が付き、旧形式も引き続き読み取れます。

- 活動の記録、スクリーンショット、サマリーはこの PC 内に保存されます。キーボードの入力内容は記録しません。リモートの AI を使う場合、送信されるのは以下に挙げる内容だけです。
- ブラウジング記録は既定でオフです。明示的に有効にした場合のみ、Windows UI Automation 経由で対応ブラウザのアドレスバーを読み取ります。サイトの記録はドメインのみを保存し、パス、クエリパラメータ、ページ内容は保存しません。スクリーンスナップショットは独立したスイッチで制御します。
- ロック中とスリープ中は前面の活動を書き込まず、スクリーンショットも撮影しません。
- 機密キーワード（アプリ名、タイトル、サイトで判定）に一致した前面ウィンドウは、タイトルを `[敏感窗口]` として保存し、スクリーンショットもサイトの記録も行いません。キーワードは設定で追加・削除できます。
- AI 提案では、ローカルで計算した匿名化済みの根拠のみを送信します：滞在時間、回数、分類、アプリ名、切り詰めたウィンドウタイトル、そしてローカルで集計した長期ワークプロファイル（ツール名、行き来するアプリの組、リズム、繰り返し現れるウィンドウタイトル）。チャット系アプリはアプリ名のみを送信し、会話のタイトルは送信しません。**スクリーンショットそのものと閲覧サイトのドメインは提案モデルに送信されません**。サイトの一覧はローカルのレポートにのみ表示されます。スクリーンショット時間帯のサマリー（有効にしている場合）はテキストとして根拠になります。
- スクリーンショット時間帯の分析は既定でオフです。有効にすると、スナップショットは上で設定したモデルのエンドポイント（ローカルまたはクラウド）に送信されます。画面にはウィンドウタイトル、サイトのアドレス、チャット内容、その他の機密情報が含まれる可能性があるため、プライバシーが気になる場合はローカルのマルチモーダルモデルを使用してください。
- オンラインでのリソース検索は既定でオフです。有効にすると、検索サービスは組み込みの抽象的なツールキーワードのみを受け取り、ウィンドウタイトル、サイトのドメイン、URL、スクリーンショット、ユーザー行動の統計は送信されません。参照リンクの検証では公開アドレスのみにアクセスします。
- テキストは送信前に、メールアドレス、キーとトークン、クレジットカード番号、身分証明書番号、電話番号、IP、パラメータ付きのリンク、`C:\Users\<用户名>` のパスをマスクします。プライバシーが気になる場合はローカルモデルを使用してください。
- スナップショットは前面ウィンドウのあるモニターを撮影します。機密キーワードは前面のアプリ、タイトル、サイトで判定するため、背景のウィンドウ内にある機密内容は識別できません。

## 開発

stable Rust（MSVC toolchain）と Visual Studio 2022 の C++ ビルドツールをインストールし、次を実行します。

```bash
cargo run
```

`start.cmd` をダブルクリックしてもかまいません。

### セルフテスト

```bash
cargo test                  # 設定、保存、統計、匿名化、推薦、模擬 AI の一連の流れ
cargo run -- --native-smoke # 実際の前面ウィンドウの収集と JPEG スクリーンショット
```

`scripts\smoke.cmd` を実行してもかまいません。ネイティブ smoke は一時ディレクトリを使用し、終了後にテスト用の記録とスクリーンショットを削除するため、実際のデータは汚しません。

### パッケージング

[NSIS 3](https://nsis.sourceforge.io/) をインストールし、次を実行します。

```bat
scripts\dist.cmd
```

スクリプトは `cargo build --release` を実行し、`dist\TraceBit Setup <バージョン>.exe` を生成します。配布されるプログラムはアイコンを埋め込んだ `tracebit.exe` のみで、Electron ランタイムや PowerShell スクリプトは含みません。

`v*` タグをプッシュすると、`.github/workflows/release.yml` が自動でビルドし、インストーラーを該当する Release にアップロードします。コミットと PR については `.github/workflows/ci.yml` が fmt、clippy、test、release ビルドを実行します。

### ディレクトリ構成

```text
src/
  main.rs            # プログラムのエントリポイントと smoke コマンド
  app.rs             # GPUI ウィンドウ、4 ページの UI、トレイ、バックグラウンドタスク
  input.rs           # ネイティブな GPUI テキスト入力コンポーネント
  platform.rs        # Win32、UIA、ウィンドウアイコン、スタートアップ、通知
  i18n.rs            # 簡体字中国語 / English / 日本語 / 한국어 のテキスト選択と言語検出
  recorder.rs        # 収集スレッド、スクリーンショットの重複排除、プライバシールール
  store.rs           # JSONL の日別保存とタイムライン／活動段／アプリ／サイト／分類の統計
  stats.rs           # 一定期間の周期統計の集計
  insights.rs        # ローカル指標と番号付きの根拠（集中作業、中断、断片化、トレンド）
  profile.rs         # 長期ワークプロファイル：ツール、行き来、リズム、繰り返すプロジェクト、ツールの決定
  analyzer.rs        # 提案の生成：プロンプト、JSON 検証、ワークプロファイル、能力境界のフィルタ、Markdown レンダリング
  report_html.rs     # 提案の独立した HTML レポート
  llm.rs             # OpenAI 互換の呼び出し：JSON モード、再試行、打ち切りの検出
  redact.rs          # 送信前の匿名化とタイトルの整形
  secret.rs          # DPAPI によるキーの暗号化
  intervals.rs       # スクリーンショット時間帯の分析、マルチモーダルリクエスト、画像エンコード、サマリーの保存
  recommendations.rs # ローカルでの操作認識と厳選リソース（AI のツール候補）
  web_search.rs      # 任意の抽象検索、フィルタ、参照元の検証
  categories.rs      # アプリとサイトの分類、会議の判定
  settings.rs        # 旧版の camelCase に対応したローカル設定
assets/              # ビルド時に埋め込まれるアイコン
build.rs             # Windows exe のアイコンリソース
installer.nsi        # NSIS インストーラーの定義
scripts/dist.cmd     # Release とインストーラーのビルド
scripts/smoke.cmd    # ユニットテストと実際の収集の smoke
```
